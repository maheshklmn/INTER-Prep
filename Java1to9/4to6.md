🧱 LEVEL 4 – Methods & Arrays

1️⃣ What is a method?

Block of code to perform a task

Improves code reusability



---

2️⃣ Difference between method and function?

Java has methods only

Functions exist inside classes in Java



---

3️⃣ What is method overloading?

Same method name

Different parameters

Compile-time polymorphism



---

4️⃣ Can we overload main() method?

✅ Yes

JVM calls only original main(String[] args)



---

5️⃣ What is an array?

Stores multiple values of same type

Fixed size



---

6️⃣ Difference between array and ArrayList?

Array → fixed size

ArrayList → dynamic size



---

7️⃣ What is 2D array?

Array of arrays

Used for matrix-like data



---

🧠 LEVEL 5 – OOP Concepts (VERY IMPORTANT 🔥)

8️⃣ What is OOP?

Programming based on objects

Improves security & reusability



---

9️⃣ What are the 4 pillars of OOP?

Encapsulation

Inheritance

Polymorphism

Abstraction



---

🔟 What is a class?

Blueprint of object

Defines properties & behavior



---

1️⃣1️⃣ What is an object?

Instance of class

Occupies memory



---

1️⃣2️⃣ What is constructor?

Special method

Same name as class

No return type



---

1️⃣3️⃣ Types of constructors?

Default

Parameterized



---

1️⃣4️⃣ What is this keyword?

Refers to current object

Resolves naming conflict



---

1️⃣5️⃣ What is encapsulation?

Data hiding

Use of private variables + getters/setters



---

1️⃣6️⃣ What is inheritance?

One class acquires another class properties

Code reusability



---

1️⃣7️⃣ Types of inheritance supported in Java?

Single

Multilevel

Hierarchical


❌ Multiple inheritance via class not supported


---

1️⃣8️⃣ Why multiple inheritance not supported?

Avoids ambiguity (Diamond problem)



---

1️⃣9️⃣ What is polymorphism?

One method, many forms



---

2️⃣0️⃣ Types of polymorphism?

Compile-time (overloading)

Runtime (overriding)



---

2️⃣1️⃣ What is method overriding?

Same method signature

Different class (inheritance)

Runtime polymorphism



---

2️⃣2️⃣ Difference between overloading and overriding?

Overloading → same class

Overriding → different class

Overloading → compile-time

Overriding → runtime



---

2️⃣3️⃣ What is abstraction?

Hiding implementation details

Showing only functionality



---

2️⃣4️⃣ Abstract class vs Interface?

Abstract Class	Interface

Can have methods with body	Methods are abstract
Supports constructors	No constructors
Multiple inheritance ❌	Multiple inheritance ✅

📦 LEVEL 6 – Core Java Advanced

2️⃣5️⃣ What is String?

Immutable object

Stored in String pool



---

2️⃣6️⃣ Difference between String and StringBuilder?

String → immutable

StringBuilder → mutable & faster



---

2️⃣7️⃣ What is static keyword?

Belongs to class

Shared among objects



---

2️⃣8️⃣ What is final keyword?

final variable → constant

final method → cannot override

final class → cannot inherit



---

2️⃣9️⃣ What are packages?

Group of related classes

Improves modularity



---

3️⃣0️⃣ Access modifiers in Java?

public

private

protected

default



---

3️⃣1️⃣ Default access modifier?

Package-private (no keyword)



---

3️⃣2️⃣ Can we override static method?

❌ No (method hiding only)
