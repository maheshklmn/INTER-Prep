⚠️ LEVEL 7 – Exception Handling & Collections

1️⃣ What is an exception?

Runtime error

Disrupts normal program flow



---

2️⃣ Difference between error and exception?

Error → serious, not recoverable (OutOfMemory)

Exception → recoverable (IOException)



---

3️⃣ Types of exceptions?

Checked (compile-time)

Unchecked (runtime)



---

4️⃣ Example of checked exception?

IOException

SQLException



---

5️⃣ Example of unchecked exception?

NullPointerException

ArithmeticException



---

6️⃣ What is try–catch block?

Handles exception

Prevents program crash



---

7️⃣ Purpose of finally block?

Always executes

Used for cleanup



---

8️⃣ Can finally block be skipped?

❌ No

Except System.exit()



---

9️⃣ What is throw vs throws?

throw → explicitly throw exception

throws → declare exception



---

🔟 What is custom exception?

User-defined exception

Extends Exception class



---

📦 Collections Framework (VERY IMPORTANT 🔥)

1️⃣1️⃣ What is Collection?

Group of objects

Dynamic size



---

1️⃣2️⃣ Difference between List and Set?

List → allows duplicates

Set → no duplicates



---

1️⃣3️⃣ Difference between ArrayList and LinkedList?

ArrayList → fast access

LinkedList → fast insertion/deletion



---

1️⃣4️⃣ Difference between HashSet and TreeSet?

HashSet → no order

TreeSet → sorted



---

1️⃣5️⃣ Difference between HashMap and Hashtable?

HashMap → not synchronized, allows one null key

Hashtable → synchronized, no null key



---

1️⃣6️⃣ Can HashMap have duplicate keys?

❌ No

Value gets replaced



---

1️⃣7️⃣ What is Iterator?

Used to traverse collection

One-directional



---

🧵 LEVEL 8 – Multithreading & File Handling

1️⃣8️⃣ What is thread?

Lightweight process

Executes task concurrently



---

1️⃣9️⃣ Difference between process and thread?

Process → heavyweight

Thread → lightweight, shares memory



---

2️⃣0️⃣ How to create thread?

Extend Thread class

Implement Runnable interface



---

2️⃣1️⃣ Difference between start() and run()?

start() → creates new thread

run() → normal method call



---

2️⃣2️⃣ What is synchronization?

Controls shared resource access

Prevents data inconsistency



---

2️⃣3️⃣ What is deadlock?

Threads wait forever for resources



---

📁 File Handling

2️⃣4️⃣ What is file handling?

Reading/writing data to file



---

2️⃣5️⃣ FileReader vs FileWriter?

FileReader → read

FileWriter → write



---

🚀 LEVEL 9 – JVM, Memory & Advanced

2️⃣6️⃣ What is JVM?

Executes bytecode

Manages memory & GC



---

2️⃣7️⃣ Stack vs Heap?

Stack → method calls, local variables

Heap → objects



---

2️⃣8️⃣ What is garbage collection?

Automatic memory cleanup

Removes unused objects



---

2️⃣9️⃣ When object is eligible for GC?

No reference pointing to it



---

3️⃣0️⃣ == vs .equals()?

== → reference

.equals() → content



---

3️⃣1️⃣ Why String is immutable?

Security

Memory optimization

Thread safety



---

3️⃣2️⃣ What is String Pool?

Special memory area in heap

Stores String literals
