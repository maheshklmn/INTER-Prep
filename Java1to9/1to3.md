🔰 LEVEL 1 – Java Basics (Most Asked)

1️⃣ What is Java?

Object-Oriented programming language

Platform independent

Uses JVM to run code



---

2️⃣ Why is Java platform independent?

Java compiles to bytecode

Bytecode runs on JVM

JVM is platform-specific, bytecode is not



---

3️⃣ What is JVM?

Java Virtual Machine

Executes bytecode

Manages memory & GC



---

4️⃣ Difference between JDK, JRE, and JVM?

JVM → runs bytecode

JRE → JVM + libraries

JDK → JRE + compiler



---

5️⃣ Why is main() method static?

JVM calls it without creating object

Entry point of program



---

6️⃣ What is bytecode?

Intermediate code generated by Java compiler

Stored in .class file



---

7️⃣ Can we run Java program without main()?

❌ No (from Java 7 onwards)



---

🧮 LEVEL 2 – Variables & Data Types

8️⃣ What is a variable?

Named memory location

Stores data



---

9️⃣ Types of variables in Java?

Local variable

Instance variable

Static variable



---

🔟 What are data types?

Define type of data stored

Example: int, double, char



---

1️⃣1️⃣ Difference between primitive and non-primitive?

Primitive → stores value (int, char)

Non-primitive → stores reference (String, array)



---

1️⃣2️⃣ What is type casting?

Converting one data type to another


Example:

int a = (int) 10.5;


---

1️⃣3️⃣ What is Scanner class?

Used to take input from user

Belongs to java.util package



---

1️⃣4️⃣ Difference between == and =?

= → assignment

== → comparison



---

🔁 LEVEL 3 – Control Flow

1️⃣5️⃣ What is control statement?

Controls flow of execution

Examples: if, loop, switch



---

1️⃣6️⃣ Difference between if and switch?

if → conditions

switch → fixed values



---

1️⃣7️⃣ Types of loops in Java?

for

while

do-while



---

1️⃣8️⃣ Difference between while and do-while?

while → may not execute

do-while → executes at least once



---

1️⃣9️⃣ What is break?

Terminates loop or switch



---

2️⃣0️⃣ What is continue?

Skips current iteration



---

2️⃣1️⃣ Difference between for and while?

for → fixed iterations

while → condition-based



---

2️⃣2️⃣ Can switch work with String?

✅ Yes (from Java 7)
